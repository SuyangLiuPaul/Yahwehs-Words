# 搜索范围与拼音移除 — 2026-10-08

## 本次源码调整

- 查询旁直接提供整本圣经、希伯来圣经、希腊圣经快捷范围；它们限制当前译本的书卷，不切换成原文译本。
- Words 同步约束文本、AI 引用、Strong’s 与布尔检索；范围名称、书卷统计与 Strong’s 数量采用同一过滤条件。
- Sword 复用现有搜索范围 provider，与书卷选择器保持一致，选择后重新执行当前查询；当前译本不含该范围时保留原范围并提示。
- 两个 app 移除拼音搜索按钮及实际匹配路径。升级时清除旧拼音偏好，保留模糊搜索偏好。
- 模糊搜索保留精确优先、简繁写法、已证实的圣经名称别称、英文词形及多片段匹配；说明改为这些真实能力，不承诺任意同义词或语义检索。
- 保留 Strong’s 编号和运算符的既有精确规则。经文、版本号与发布标签未修改。

## 验证与边界

- 两个工作树 Flutter analyze 均无问题。
- 更新旧设置迁移与按钮测试，覆盖 320/402/1024 宽度及 1.8 倍文字缩放；Words 增加 66 卷范围分区/中英文书卷测试及模糊搜索不会隐式执行拼音的回归测试。
- 本地 Flutter test 启动被 Xcode 尚未接受许可导致的 objective_c 原生 hook 阻挡；没有接受许可或绕过原生设置。必须检查 PR 最新提交的完整 Linux CI 成功后合并，不将未启动的本地测试报告为通过。
- 用户授权本地提交、push 与合并 main。本记录本身不代表商店安装包或网站已部署此搜索调整。

## 本地预览反馈后的排版收尾

- 用户要求 Words 与 Sword 搜索控件横向居中。范围按钮采用居中 Wrap，模糊搜索与说明采用同一宽度并居中，说明与按钮间增加间距。
- 窄屏继续自动换行；保留按钮状态、检索逻辑和操作回调。
- 两个本地 Web 调试服务均已重新编译成功。后续 push/合并应核对该排版提交的最新 CI，不能复用前一个搜索功能提交的结果。
